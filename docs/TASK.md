# Проект VK Education — Веб-мессенджер

**Источник:** [VK Education Projects](https://education.vk.company/education_projects)

---

## 1. Цель проекта

Сделать веб-мессенджер с личными и групповыми чатами, доставкой сообщений в реальном времени, хранением истории и базовой модерацией.

## 2. Описание проекта

Необходимо разработать веб-мессенджер с личными и групповыми чатами, доставкой сообщений в реальном времени, хранением истории и базовой модерацией.

### MVP (обязательный минимум)

- **Регистрация и вход:** JWT + refresh token или упрощённо только JWT.
- **Список чатов:** личный чат 1-1; групповой чат с возможностью создания и указания названия.
- **Сообщения:**
  - Отправка и получение в реальном времени через WebSocket/gRPC.
  - История сообщений с пагинацией при прокрутке вверх.
  - Статус «доставлено» как минимум на уровне доставки на сервер.
- **Участники:** добавление и удаление участников группового чата только администратором.
- **Поиск:** поиск сообщений по простой строке в рамках выбранного чата.

### Дополнительные возможности

- Статус «прочитано» для каждого пользователя.
- Редактирование и удаление сообщений с отметкой `edited`.
- Реакции на сообщения: лайк, смех и другие.
- Вложения: изображения и файлы с хранением на диске или в S3-аналоге.
- Упоминания `@user` и ответы `reply`.
- Отключение уведомлений (`mute`) хотя бы на уровне флага.
- Антиспам: ограничение частоты отправки сообщений (`rate limit`).
- Суммаризатор переписки на основе LLM.

### Пользовательский интерфейс (при наличии frontend-части)

- Экран входа.
- Список чатов и поиск.
- Окно чата: сообщения, поле ввода, кнопка «Загрузить ещё».
- Модальное окно создания группового чата и добавления участников.

## 3. Алгоритм выполнения проекта

1. Изучение современных подходов к проектированию серверной и клиентской частей мессенджера.
2. Проектирование архитектуры и выбор технологии быстрой доставки сообщений.
3. Изучение работы с базами данных и, при необходимости, брокерами сообщений.
4. Разработка решения и проектирование API.
5. Тестирование и отладка.

## 4. Необходимые навыки и компетенции

- Backend-разработка.
- Работа с базами данных.
- System Design.

## 5. Ожидаемый результат

Разработанный веб-мессенджер с личными и групповыми чатами, доставкой сообщений в реальном времени, хранением истории и базовой модерацией.
