# API веб-мессенджера

**Версия:** 1.0

## 1. Общая информация

Для взаимодействия frontend и backend используются:

- **REST API** — авторизация, работа с пользователями, чатами и историей сообщений.
- **WebSocket** — отправка и получение сообщений в реальном времени, уведомления.

Для доступа к защищённым запросам используется JWT.

## 2. REST API

### 2.1. Авторизация

| Метод | Endpoint         | Описание       |
| ----- | ---------------- | -------------- |
| POST  | `/auth/register` | Регистрация    |
| POST  | `/auth/login`    | Вход в аккаунт |

### 2.2. Пользователи

| Метод | Endpoint | Описание            |
| ----- | -------- | ------------------- |
| GET   | `/users` | Поиск пользователей |

### 2.3. Чаты

| Метод  | Endpoint                       | Описание                           |
| ------ | ------------------------------ | ---------------------------------- |
| GET    | `/chats`                       | Получение списка своих чатов       |
| POST   | `/chats/private`               | Создание или открытие личного чата |
| POST   | `/chats/group`                 | Создание группового чата           |
| POST   | `/chats/{id}/members`          | Добавление участника в группу      |
| DELETE | `/chats/{id}/members/{userId}` | Исключение участника из группы     |
| POST   | `/chats/{id}/leave`            | Выход из группы                    |
| PATCH  | `/chats/{id}/notifications`    | Настройка уведомлений чата         |

### 2.4. Сообщения

| Метод | Endpoint                      | Описание                                 |
| ----- | ----------------------------- | ---------------------------------------- |
| GET   | `/chats/{id}/messages`        | Получение истории сообщений с пагинацией |
| GET   | `/chats/{id}/messages/search` | Поиск сообщений внутри чата              |

## 3. WebSocket API

| Событие          | Направление     | Описание                            |
| ---------------- | --------------- | ----------------------------------- |
| `send_message`   | Клиент → Сервер | Отправка сообщения                  |
| `message_saved`  | Сервер → Клиент | Подтверждение сохранения сообщения  |
| `new_message`    | Сервер → Клиент | Получение нового сообщения          |
| `message_error`  | Сервер → Клиент | Ошибка при отправке                 |
| `member_added`   | Сервер → Клиент | Уведомление о добавлении в группу   |
| `member_removed` | Сервер → Клиент | Уведомление об исключении из группы |

Для непросмотренных сообщений используются счётчики, которые возвращаются при загрузке списка чатов. Способ обновления счётчиков через WebSocket уточним при проектировании контрактов.

Подробные форматы событий описаны в [WEBSOCKET.md](WEBSOCKET.md).

## 4. Маршруты frontend

| Маршрут          | Страница                     |
| ---------------- | ---------------------------- |
| `/login`         | Вход в аккаунт               |
| `/register`      | Регистрация                  |
| `/`              | Главная страница мессенджера |
| `/chats/:chatId` | Страница выбранного чата     |

При попытке открыть защищённую страницу без авторизации пользователь перенаправляется на `/login`.

Отдельный REST-эндпоинт для главной страницы не нужен. Данные загружаются через существующие API.
